# 👗 Venive

Tienda de ropa en línea hecha en PHP con el patrón **MVC**: catálogo por categoría y género, tallas, inventario y administración de productos.

![PHP](https://img.shields.io/badge/PHP-777BB4?style=flat-square&logo=php&logoColor=white)
![SQL](https://img.shields.io/badge/SQL-4479A1?style=flat-square&logo=mysql&logoColor=white)
![CSS](https://img.shields.io/badge/CSS-1572B6?style=flat-square&logo=css3&logoColor=white)

## ✨ Funcionalidades

- Registro, inicio y cierre de sesión.
- Catálogo por secciones: hombre, mujer, deportiva, blusas, chaquetas, pantalones.
- Crear y editar productos.
- Manejo de categorías, tallas e inventario.

## 🚀 Cómo correrlo

1. Requisitos: PHP y un servidor de base de datos.
2. Creá la base con `DB_Venive.sql`.
3. Ajustá la conexión en la carpeta `Db/`.
4. Abrí `View/index.php` desde tu servidor local.
